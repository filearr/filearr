Scan controls

      
These settings change what this agent does —
        when it scans and which folders it walks. They never change the catalog:
        the local surface stays read-only over items and metadata. Every control
        is permitted (or not) by the central policy, and a setting central has
        explicitly set is shown here but edited in the console.

A share mapping tells central how a file under
        this root is reached from another machine, so the catalog can offer a
        network-open link. Accepted forms:
        smb://host/share[/sub], \\host\share[\sub],
        nfs://host/export — an Unraid host typically maps
        /mnt/user/media=smb://tower/media. A root with no mapping is
        cataloged normally; it just carries no network location.
        Precedence: FILEARR_AGENT_SHARE_MAP (this machine's environment) >
        mapping saved here > share discovered on the host. A path the
        environment maps is shown read-only — it is set where this agent is
        deployed (compose file, Unraid template), and a value saved here would
        never be used.
